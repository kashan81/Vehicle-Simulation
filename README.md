Intelligent Multi-Vehicle Traffic Simulation System (C++ OOP)
Overview

This project is a traffic simulation system developed in C++ using Object-Oriented Programming (OOP). It models real-time vehicle movement, multi-vehicle interaction, safety distance evaluation, and collision detection using physics-inspired logic.

The system simulates a simplified traffic environment where a user-controlled vehicle interacts with AI-controlled vehicles in dynamic conditions.

Objectives

The main goal of this project is to:

Understand and implement Object-Oriented Programming concepts in C++
Simulate real-world traffic behavior using mathematical models
Apply physics-based formulas for motion and braking
Develop a structured software system with modular design
Demonstrate real-time decision-making in a simulation environment
Features
Vehicle Simulation
Player-controlled vehicle (acceleration, braking, emergency braking)
AI-controlled vehicles with dynamic speed behavior
Traffic Intelligence
Multi-vehicle interaction system
Lane-based vehicle placement (basic traffic structure)
Relative movement simulation between vehicles
Safety System
Reaction-time-based safe distance calculation
Real-time risk analysis:
SAFE
WARNING
CRITICAL RISK
Collision Detection
Detects when distance becomes zero or negative
Ends simulation upon collision event
Real-Time Simulation
Each loop represents 1 second of simulation time
Dynamic update of speed and distance values
